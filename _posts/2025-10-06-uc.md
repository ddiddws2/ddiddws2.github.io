### ⚙️  設定方法
#### 1. スターターテンプレートからクローンしてレポジトリを作成
```shell
git clone https://github.com/cotes2020/chirpy-starter.git my-blog
cd my-blog
```
<br>

#### 2. リポジトリとリンク付け
```shell
git add .
git commit -m "Initial commit"
git push -u origin main
```

### 👿  トラブルシューティング
#### 1. ＿siteの中身が勝手に上書きされる。 
> **_siteは動的に生成されるため、勝手に触っちゃダメ。** 
{: .prompt-warning }

<br>
> I want to change the font-family but every changes I made inside the style.css located at _site/assets/css gets removed whenever I run bundle exec jekyll s <br>What am I doing wrong? I want to add a google web font called Inter.

Well, first of all you should not make any changes inside _site directory. As you might noticed, this **folder is not a part of this repository.** It's being created when you build your instance of the site, so it is fully generated from the source code. Taking this into account, you have to make changes in the source code instead of generated files.

Making changes in the source code files depends on what exact thing you would like to change as things resides in different places. Also, keep in mind that this is not a blog engine rather than blog theme. This means that some things are created specifically to look like that were designed. However, there are ways to change things except modifying _config.yml. Besides configuration file, there are mechanisms in place that allows you to make customizations like assets/css/jekyll-theme-chirpy.scss allowing to add custom styles.

Typically, when you want to override something, you need to copy a file from original repo and place it at the same place in your fork and modify as you wish. However, doing so will mean that you are the only person responsible to support these changes and make sure they still work on every blog version update.

In this particular case, please refer to the answer given already.

Hope this helps someone.

{: .prompt-tip }

#### 3. サイドバーのProfile画像いらない 
> 解決策<br> _config.ymlのavatarをコメントアウト<br> 
`#avatar:`<br><br>
>_includes/sidebar.htmlのavatar部分削除<br>
```markdown
<a href="{{ '/' | relative_url }}" id="avatar" class="rounded-circle">
    {%- if site.avatar != empty and site.avatar -%}
    {%- capture avatar_url -%}
        {% include media-url.html src=site.avatar %}
    {%- endcapture -%}
<img src="{{- avatar_url -}}" width="112" height="112" alt="avatar" onerror="this.style.display='none'">
    {%- endif -%}
</a>
``` 
{: .prompt-tip }
