### ☀️ Chirpyとは
- Rubyベースの静的サイトジェネレータJekyllのテーマの一つ。<br>
- 製作者:[cotes chung](https://cotes.page/about/) 
- 以下、作成経緯一部抜粋

> 2016年以降、グレート・ファイアウォール内のブログプラットフォームは、ユーザーに携帯電話番号のリンクを要求したり、料金を請求したりするようになり、ユーザー情報の漏洩や売買が頻発しています。今後、詐欺電話や嫌がらせ電話を受ける可能性を減らすため、私はこのスキャンダラスなコミュニティから離れることにしました。<br><br>その後、私は多くの技術的な問題や生活上の問題の解決策をEvernoteに書き留めるようになりました。Evernoteはあくまでメモを取るためのプラットフォームであり、ブログのような自由度は提供していません。そのため、個人ブログを立ち上げる必要性がさらに高まりました。<br><br>振り返ってみると、何年も前にWordPressという非常に人気の高いサービスを試してみました。少し使ってみただけで、複雑すぎる、肥大化している、そしてハードウェアへの負荷が高いと感じました。アメリカのVPSで数ヶ月間運用しましたが、記事を1つも書けませんでした。そして最終的に、そのVPSの有効期限が切れた時、WordPressは私の生活から消えてしまいました。<br><br>2017年末、JekyllとGitHub Pagesを組み合わせるという新しいアプローチに出会いました。Jekyllは、軽量でコンパクト、そしてハードウェア負荷の少ない静的サイトを作成できる成熟した静的サイトジェネレーターです。一方、GitHub Pagesはウェブサイトをホスティングするための無料ウェブサーバーです。自分の技術経験や人生経験を保存・共有するのに、最も経済的で安定した方法を使うのはいかがでしょうか？そこで、すぐにこのソリューションの実現可能性を調査しました。 
<br>
<br>

### ⚙️ 設定方法
#### 1. スターターテンプレートからクローンしてレポジトリを作成
```shell
git clone https://github.com/cotes2020/chirpy-starter.git my-blog
cd my-blog
```
<br>

#### 2. リポジトリとリンク付け
```shell
git add .
git commit -m "Initial commit"
git push -u origin main
```
