## コンパイラの主な挙動
例えば、以下のコマンドだと、実行ファイルのみが生成されるが、
結果として出力されていないだけで、実際にはもっと多くの内容物が作成されている。
```bash
gcc main.c -o main
```
<br>

### 実際の挙動(GCC)
```mermaid
%%{init: {'theme':'neutral'}}%%
flowchart LR;
A[Pre-Processor]
A --> B[Compiler]
B --> C[Assembler]
C --> D[Linker]
```

<br>

### それぞれの挙動の内容

|挙動|内容|
|---|---|
|Pre-Processor|1. コメントの削除をして、使ってない部分を削除<br> 2. インクルードされたヘッダーファイルを読み込んで展開|
|Compiler|元の言語をアセンブリに変換|
|Assembler|0と1から構成される機械語に変換→オブジェクトファイル|
|Linker|共有ライブラリなどで利用されている箇所をオブジェクトファイルに<br>リンクする(ダイナミックリンキング)|



<br><br>

Cで簡単な”Hello World"を出力する例

```c
#include <stdio.h>

int main(void) {
 printf("Hello,world\n");
}
```

↓↓↓ Assembly

```bash
	.section	__TEXT,__text,regular,pure_instructions
	.build_version macos, 16, 0	sdk_version 26, 0
	.globl	_main                           ; -- Begin function main
	.p2align	2
_main:                                  ; @main
	.cfi_startproc
; %bb.0:
	stp	x29, x30, [sp, #-16]!           ; 16-byte Folded Spill
	mov	x29, sp
	.cfi_def_cfa w29, 16
	.cfi_offset w30, -8
	.cfi_offset w29, -16
	adrp	x0, l_.str@PAGE
	add	x0, x0, l_.str@PAGEOFF
	bl	_printf
	mov	w0, #0                          ; =0x0
	ldp	x29, x30, [sp], #16             ; 16-byte Folded Reload
	ret
	.cfi_endproc
                                        ; -- End function
	.section	__TEXT,__cstring,cstring_literals
l_.str:                                 ; @.str
	.asciz	"Hello,world\n"

.subsections_via_symbols
```
<br>

#### Assembly 1行ごとの解説

|No.|Line|Explanation|
|---|---|---|
|1|	.section	__TEXT,__text,regular,pure_instructions    | Code section for executable instructions|
|2|	.build_version macos, 16, 0	sdk_version 26, 0          | Build version metadata for MacOS|
|3|	.globl	_main                           ; -- Begin function main  | Mark _main as a global entry point (the program's main function)|
|4|	.p2align	2                                             | Align the main function to a 4-byte boundary in memory|
|5|_main:                                  ; @main|
|6|	.cfi_startproc                                        | Start of the call frame information for debugging/unwinding|
|7|; %bb.0:                                                  | Basic block label (not important for the logic)|
|8|	stp	x29, x30, [sp, #-16]!           ; 16-byte Folded Spill    | Save the old frame pointer (x29) and link register (x30) to stack and update stack pointer|
|9|	mov	x29, sp                                           | Set current frame pointer (x29) to current stack pointer (sp) for this function|
|10|	.cfi_def_cfa w29, 16                                   | Set the call frame address info (for unwinding/debugging)|
|11|	.cfi_offset w30, -8                                    | More call frame info (offset for x30)|
|12|	.cfi_offset w29, -16                                   | More call frame info (offset for x29)|
|13|	adrp	x0, l_.str@PAGE                                 | Load the page address where the "Hello,world\n" string resides into register x0 (the printf first argument)|
|14|	add	x0, x0, l_.str@PAGEOFF                            | Add the offset within the page to get full address of the string into x0|
|15|	bl	_printf                                           | Branch-with-link to call printf(x0), which prints "Hello,world\n"|
|16|	mov	w0, #0                          ; =0x0              | Set return value of main() to 0 in w0 ("return 0;")|
|17|	ldp	x29, x30, [sp], #16             ; 16-byte Folded Reload | Restore old frame pointer and link register, reset stack pointer|
|18|	ret                                                    | Return from main()|
|19|	.cfi_endproc                                           | End of call frame information|
|20|                                        ; -- End function|
|21|	.section	__TEXT,__cstring,cstring_literals             | Section for storing literal strings|
|22|l_.str:                                 ; @.str|
|23|	.asciz	"Hello,world\n"                                 | The string "Hello,world\n" to print|
|24|.subsections_via_symbols                                   | Directive for the linker|
