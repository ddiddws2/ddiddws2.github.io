## コンパイラの主な挙動
例えば、以下のコマンドだと、実行ファイルのみが生成されるが、
結果として出力されていないだけで、実際にはもっと多くの内容物が作成されている。
```bash
gcc main.c -o main
```
<br>

### 実際の挙動(GCC)
```mermaid
%%{init: {'theme':'neutral'}}%%
flowchart LR;
A[Pre-Processor]
A --> B[Compiler]
B --> C[Assembler]
C --> D[Linker]
```

<br>

### それぞれの挙動の内容

|挙動|内容|
|---|---|
|Pre-Processor|1. コメントの削除をして、使ってない部分を削除<br> 2. インクルードされたヘッダーファイルを読み込んで展開|
|Compiler|元の言語をアセンブリに変換|
|Assembler|0と1から構成される機械語に変換→オブジェクトファイル|
|Linker|共有ライブラリなどで利用されている箇所をオブジェクトファイルに<br>リンクする(ダイナミックリンキング)|



<br><br>

Cで簡単な”Hello World"を出力する例

```c
#include <stdio.h>

int main(void) {
 printf("Hello,world\n");
}
```

↓↓↓ Assembly

```bash
	.section	__TEXT,__text,regular,pure_instructions
	.globl	_main                           ; -- Begin function main
	.p2align	2
_main:                                  ; @main
	adrp	x0, l_.str@PAGE
	add	x0, x0, l_.str@PAGEOFF
	bl	_printf
	mov	w0, #0                          ; =0x0
	ret
	.section	__TEXT,__cstring,cstring_literals
l_.str:                                 ; @.str
	.asciz	"Hello,world\n"
.subsections_via_symbols
```
<br>

#### Assembly 1行ごとの解説

|No.|Line|Explanation|
|---|---|---|
|1|	.section	__TEXT,__text,regular,pure_instructions    | Code section for executable instructions|
|2|	.globl	_main                           ; -- Begin function main  | Mark _main as a global entry point (the program's main function)|
|3|	.p2align	2                                             | Align the main function to a 4-byte boundary in memory|
|4|_main:                                  ; @main|
|5|	adrp	x0, l_.str@PAGE                                 | Load the page address where the "Hello,world\n" string resides into register x0 (the printf first argument)|
|6|	add	x0, x0, l_.str@PAGEOFF                            | Add the offset within the page to get full address of the string into x0|
|7|	mov	w0, #0                          ; =0x0              | Set return value of main() to 0 in w0 ("return 0;")|
|8|	ret                                                    | Return from main()|
|9|	.section	__TEXT,__cstring,cstring_literals             | Section for storing literal strings|
|10|l_.str:                                 ; @.str|
|11|	.asciz	"Hello,world\n"                                 | The string "Hello,world\n" to print|
|12|.subsections_via_symbols                                   | Directive for the linker|
