### 🧜‍♀️ Mermaidとは
- JavaScriptベースの図表作成ツール
- 製作者:[Knut Sveidqvist](https://github.com/knsv) 
- 製作年度:2014 
<br><br>

> Jekyll環境においては、mermaidを使いたいページのヘッダーに<br>**mermaid: true** を記載すること
{: .prompt-warning }

<br><br>

###  ◽利用できる図
代表的な図のみ記載詳しくは、公式ページを参照

> #### フローチャート<br>
```mermaid
%%{init: {'theme':'neutral'}}%%
flowchart TB;
A[図を作成する] --> B[Mermaidを使って作図];
B -- プロジェクトや予定の流れをまとめる --> C{フローチャート};
B -- プロジェクト管理や生産管理 --> D{ガントチャート};
B -- 数値や割合をグラフにする --> E{円グラフ};
B -- アイデアや情報の流れを見える化 --> F{マインドマップ};
``` 
[参照:フローチャート構文](https://docs.min87.com/ja/mermaid/syntax/flowchart.html)
{: .prompt-info }

<br>

> #### ガントチャート<br>
```mermaid
%%{init: {'theme':'neutral'}}%%
gantt
    title ガントチャートサンプル
    dateFormat YYYY-MM-DD
    section チャート作成 
        どのチャートにするか決める          :a1, 2014-01-01, 30d
        承認もらう    :after a1, 20d
    section 予算作成 
        別のタスク :b1, 2014-01-15, 12d
        承認もらう    :after b1, 20d
```
[参照:ガントチャート構文](https://docs.min87.com/ja/mermaid/syntax/gantt.html)
{: .prompt-info }

<br>

> #### 円グラフ<br>
```mermaid
%%{init: {"pie": {"textPosition": 0.5}, "themeVariables": {"pieOuterStrokeWidth": "5px"}} }%%
pie showData
    title Aproject 年代別構成比
    "20代" : 15
    "30代" : 36
    "40代～" : 22
```
[参照:円グラフ構文](https://docs.min87.com/ja/mermaid/syntax/pie.html)
{: .prompt-info }

<br>

> #### シーケンス図<br>
```mermaid
sequenceDiagram
    Alice->>Bob: こんにちはボブ、お元気ですか？
    Bob->>Alice: 元気です、ありがとう。そしてあなたは？
    create participant Carl
    Alice->>Carl: こんにちはカール！
    create actor D as Donald
    Carl->>D: こんにちは！
    destroy Carl
    Alice-xCarl: 私たちは多すぎる
    destroy Bob
    Bob->>Alice: 同意します
```
[参照:シーケンス構文](https://docs.min87.com/ja/mermaid/syntax/sequenceDiagram.html)
{: .prompt-info }

<br>

> #### マインドマップ<br>
```mermaid
%%{init: {'theme':'neutral'}}%%
mindmap
  root((Markdown))
    Origins
      Long history
    Research
      On effectiveness<br/>and features
      On Automatic creation
        Uses
            Creative techniques
            Strategic planning
            Argument mapping
    Tools
      Pen and paper
      Mermaid
        Mind Map
        Flow Chart
        Gant Chart
        Pie Chart
```
[参照:マインドマップ構文](https://docs.min87.com/ja/mermaid/syntax/mindmap.html)
